# iPhone 配置与提醒

## 上传快捷指令

优先执行 `npm run shortcut`，导入 `.private/验证码上传.shortcut`。在 Mac 上导入后，可通过同一 Apple 账户的快捷指令同步到 iPhone；也可将文件私下传到自己的设备。不要上传生成文件到 GitHub、网盘公共链接或公开快捷指令目录。

如果无法签名，手工创建名为“验证码上传”的快捷指令：

1. 添加“文本”操作，内容使用“快捷指令输入”变量。输入类型允许“文本”和“信息”。
2. 添加“获取 URL 内容”，URL 为你的 HTTPS 域名加 `/api/sms`。
3. 展开更多选项：方法 `POST`，请求体 `JSON`。
4. 头部键 `Authorization`，值为 `Bearer ` 加 `.private/config.json` 中的 `upload_token`。注意 Bearer 后有一个空格，读取密钥不能代替上传密钥。
5. JSON 添加文本字段 `message`，值选择前面“文本”操作的输出变量；不要填写变量的名称作为普通字符串。
6. 不添加“显示通知”“显示提醒”等交互操作。

## 十条自动化

首次运行允许该快捷指令连接你自己的站点。尽量先解锁测试；首次权限提示未处理时，不能认为自动上传已启用。所有规则共用一个快捷指令，以后更换上传地址或密钥只需修改一处。

一条含多个不同数字的短信可能触发多次，服务端会去重。iPhone 个人自动化通常需要在设备上配置，本项目不承诺靠一个下载链接就能自动安装十条触发规则。

## 关闭“正在运行你的自动化”提醒

部分触发类型或系统版本有“运行时通知”选项，存在时可直接关闭。短信触发在实机验证的版本中没有该开关。

该设备可通过下面路径关闭“快捷指令”的系统通知：

1. 设置 → 屏幕时间（部分版本叫“屏幕使用时间”）→ 查看所有 App 与网站活动。
2. 找到页面下方的“通知”统计，选择“快捷指令”。不要误选上方的 App 使用时长。
3. 如果“快捷指令”没有可进入的箭头，切到前一天再切回今天，等待页面刷新后重试。
4. 在系统“快捷指令”通知页关闭“允许通知”。

这会影响**所有快捷指令的通知**，不是只隐藏本项目。自动化本身仍保留“立即运行”。如果需要保留其他快捷指令的提醒，可以只关闭横幅、锁屏显示和声音，并保留通知中心。

不同系统版本可能不提供此入口，重启或系统更新后也应重新检查；不要承诺所有 iPhone 都能永久静默，不要为隐藏提醒关闭系统安全保护。恢复时回到同一页打开“允许通知”。

## 真实收信验证

让另一部手机发送“测试验证码 0123456789”。检查私人 JSON 接口出现一条记录，正文正确，重复命中不会多出十条。再检查一个超过十分钟的测试记录不会被读到。

没有收到时依次检查：是否真的收到新短信、正文是否含阿拉伯数字、自动化是否立即运行、是否选择正确快捷指令、网络和首次授权、JSON `message` 是否绑定变量、是否用了上传密钥。不要把含密钥的请求或真实验证码贴到公开 Issue。
